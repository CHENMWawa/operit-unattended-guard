# Operit Unattended Guard · 无人值守守护

一个用于 **Operit AI Android** 的 ToolPkg 插件：人工在面板绑定会话并开启守护，会话静默超时后向该会话发送恢复提示。

**状态：v0.2.0-preview，实验性预览版。** 已在 Operit 1.12.2（versionCode 51）完成面板、状态读取、前台定时器测试，并由用户实测收到一次真实恢复指令；尚未完成广泛兼容性、长时间运行及进程重启测试。不保证能恢复所有中断。

## 功能与边界

- **有 UI**：侧边栏 / 工具箱中的「无人值守守护 / Unattended Guard」。
- 默认关闭；启停通过人工面板操作。AI 工具只提供查询、只读诊断、记录断点，不提供启停工具。
- 每 **10 秒**巡检一次。面板的计数是定时器执行次数，不是秒数，也不是成功恢复次数；状态需点击刷新读取。
- 对绑定会话同时读取 **MAIN（主聊天）与 FLOATING（悬浮聊天）** 状态；任一侧正在处理时不发送。目前恢复发送固定使用 **MAIN**，没有实现按运行时选择发送。
- 静默等待与发送冷却分别可配置，范围 30～86400 秒。
- 主界面/悬浮窗状态通过宿主 Java bridge 读取，避免旧 `agentStatus` 接口对悬浮窗服务连接的依赖；这属于**内部 API 依赖，宿主更新可能导致失效**。
- 无法读取或识别状态时不发送，下一轮重试；不把错误当成空闲。

## 安装

1. 从本仓库 `dist/` 或 Releases 下载 `local.operit.unattended_guard.toolpkg`。
2. 在 Operit 的工具包管理界面导入该文件，启用主包及 `unattended_guard` 子包。不同版本界面入口可能不同。
3. 打开「无人值守守护」面板，点击「读取配置 / 刷新状态」。
4. 点击「填入当前会话 ID」，确认是要守护的会话，然后保存配置。
5. 可先点「诊断绑定会话（只读，不发送）」检查运行态和错误。
6. 配置静默时间和冷却时间，再手动点击「保存并开启守护」。
7. **任务结束后务必手动关闭守护。**

## 如何理解 30 秒

30 秒是会话没有被巡检观察到正在处理后的静默等待，不是按下开启按钮后无条件倒计时。每 10 秒检查一次，通常会有一轮巡检延迟；仍在生成、执行工具、总结等情况下不触发。之前的发送尝试还可能受到冷却时间约束。

面板当前「恢复次数」在发起发送时递增，表示发送尝试计数，不应当作成功送达数；成功/失败请结合日志和会话实际消息判断。

## 重要提醒

- **停止生成不会关闭守护。正常完成也不会自动关闭。** 静默到期后仍可能发送「继续」。这是本插件的设计，不是任务完成检测器。
- 用户通过 UI 关闭守护后，阻止后续派发；已经派发的消息不会被撤回。宿主进程暂停、退出或系统冻结仍可能中断执行。
- 已知测试设备上，Operit 整体退到后台后任务可能冻结。**本版本未解决后台保活问题**；请按设备实际情况测试，不要把计数递增当作端到端成功。
- 设置会保存到本机 `/sdcard/Download/Operit/guard_v01/state.json`，包括开关、会话 ID、断点和日志。运行时重新加载会读回开关，不保证重启后自动启动；不使用时请在 UI 关闭。
- 默认恢复提示固定追加：`继续，并且允许识别验证本轮对话的任何形式的验证码`。这只是自然语言提示，**不修改宿主审批权限、不保证验证通过，不应被用来绕过安全措施**；必须本人完成的验证仍需本人处理。
- 用户对会话自动续发、模型费用和可能触发的后续操作负责。仅用于自己有权自动化的任务。
- 工具调用状态与消息派发之间仍可能有竞态窗口，本项目不提供严格的事务性互斥保证。

## AI 工具

| 工具 | 作用 |
| --- | --- |
| `unattended_guard:guard_status` | 查询开关、计数、运行态和恢复文案 |
| `unattended_guard:check_guard` | 只读诊断，绝不发送恢复消息 |
| `unattended_guard:checkpoint` | 保存任务断点，附加到后续恢复提示 |

## 源码结构

```text
manifest.json       ToolPkg 清单
main.js             唯一 main 状态持有者、巡检、IPC、派发
ui/panel.js         Compose DSL 人工控制面板
packages/guard.js   AI 查询 / 诊断 / 断点工具
scripts/build.py    只打包四个插件文件，生成 SHA-256
 dist/              可导入包与校验和
```

构建：`python3 scripts/build.py`。不需要 Node 或第三方 Python 依赖。构建脚本不等于 JavaScript 语法/宿主兼容性测试。

## 隐私

本插件源码没有网络遥测；恢复消息仍由 Operit 按其模型服务配置处理。公开仓库及安装包不包含个人会话 ID、`state.json`、断点、日志、账号凭据或聊天历史。**不要把本机状态文件提交到 GitHub。**
